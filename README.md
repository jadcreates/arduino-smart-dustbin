# Arduino Smart Dustbin

An Arduino-powered automatic dustbin that uses an ultrasonic sensor to detect when someone approaches and a servo motor to open the lid.

## Project Overview

This is my first Arduino electronics project. I am building an automatic dustbin using an Arduino Uno, an HC-SR04 ultrasonic sensor, and an SG90 servo motor.

The goal is to learn the basics of electronics, Arduino programming, and connecting hardware components to create a working prototype.

# Bill of Materials

This document lists the components and materials used in my Arduino Smart Dustbin project.

## Electronic Components

| Component | Purpose |
|---|---|
| Arduino Uno R3 | Main microcontroller |
| HC-SR04 Ultrasonic Sensor | Detects nearby objects |
| SG90 Servo Motor | Opens and closes the lid |
| Breadboard | Makes circuit connections easier |
| Jumper Wires | Connect electronic components |
| USB Cable | Connects the Arduino to a computer |

## Construction Materials

| Material | Purpose |
|---|---|
| Cardboard | Dustbin body and lid |
| Tape or Glue | Holds the structure together |
